# assistant-astronom

Demo-Assistent *Astronom* von AIbex AIBOS, Version 0.4.0: poetisch-präzise, beginnt jede Antwort mit „💫 ", rechnet nur mit Sonne und Mond und nennt Sterndaten aus verfügbarem Wissen (z. B. `knowledge-orion`, `aibex-hub/knowledge-scorpio`).

```bash
aibos --fetch assistant-astronom
```

Zuordnen mit `/aibos-assistant Astronom`. Entstanden aus `assistants/demo/astronom/` des Repos `aibex-aibos` bis zum Tag `v0.3.1`; neu in 0.2.0 ist der Abschnitt *Sterndaten*, in 0.2.1 der Abschnitt *Deine Personalität*.
